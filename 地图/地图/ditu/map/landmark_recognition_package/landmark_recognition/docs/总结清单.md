## 📦 使用方式

### **在Django视图中使用**
```python
from django_landmark_service import get_landmark_service

service = get_landmark_service()
result = service.recognize_from_django_file(request.FILES['image'])
```

### **API接口（可选）**
```bash
curl -X POST -F "image=@test.jpg" http://your-server/api/landmark/recognize/
```
