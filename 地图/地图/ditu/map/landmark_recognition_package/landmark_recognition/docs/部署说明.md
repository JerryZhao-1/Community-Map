## 🔧 使用方式

### 1. 在Django视图中使用
```python
from landmark_recognition.django_landmark_service import get_landmark_service

def my_view(request):
    service = get_landmark_service()
    
    # 从上传的文件识别
    if 'image' in request.FILES:
        result = service.recognize_from_django_file(request.FILES['image'])
        return JsonResponse(result)
```

### 2. 在Django模型中使用
```python
from django.db import models
from landmark_recognition.django_landmark_service import get_landmark_service

class UserPhoto(models.Model):
    image = models.ImageField(upload_to='photos/')
    recognized_landmark = models.CharField(max_length=200, blank=True)
    confidence = models.FloatField(default=0.0)
    
    def save(self, *args, **kwargs):
        super().save(*args, **kwargs)
        
        # 自动识别地标
        if self.image:
            service = get_landmark_service()
            result = service.recognize_from_path(self.image.path)
            if result['success']:
                self.recognized_landmark = result['landmark']
                self.confidence = result['confidence']
                super().save(update_fields=['recognized_landmark', 'confidence'])
```

## 📊 性能优化建议

### 1. 模型加载优化
```python
# 使用单例模式，避免重复加载模型
from landmark_recognition.django_landmark_service import get_landmark_service

# 在Django启动时预加载模型
def ready(self):
    get_landmark_service()  # 预加载模型
```

### 2. 异步处理
```python
# 使用Celery进行异步处理
from celery import shared_task
from landmark_recognition.django_landmark_service import get_landmark_service

@shared_task
def async_landmark_recognition(image_path):
    service = get_landmark_service()
    return service.recognize_from_path(image_path)
```

### 3. 缓存优化
```python
from django.core.cache import cache
import hashlib

def get_image_hash(image_data):
    return hashlib.md5(image_data).hexdigest()

def cached_recognition(image_data):
    cache_key = f"landmark_{get_image_hash(image_data)}"
    result = cache.get(cache_key)
    
    if result is None:
        service = get_landmark_service()
        result = service.recognize_from_base64(image_data)
        cache.set(cache_key, result, timeout=3600)  # 缓存1小时
    
    return result
```

## 🐳 Docker部署

### 1. 创建Dockerfile
```dockerfile

    libgl1-mesa-glx \
```

## 🚨 常见问题解决

### 1. 模型加载失败
```bash
# 检查模型文件路径
ls -la image_detection/best_landmark_model_finetuned.pt

# 检查文件权限
chmod 644 image_detection/best_landmark_model_finetuned.pt
```

### 2. 内存不足
```python
# 在settings.py中限制并发
LANDMARK_MAX_CONCURRENT = 3  # 最大并发数
```

### 3. CUDA相关问题
```bash
# 如果没有GPU，确保使用CPU版本
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```
