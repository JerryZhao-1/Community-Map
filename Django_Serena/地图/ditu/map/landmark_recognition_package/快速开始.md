# 🚀 快速开始指南

## 1. 环境准备
```bash
# 确保Python 3.7+环境
python --version

# 激活conda环境（如果使用conda）
conda activate community_map_env
```

## 2. 安装依赖
```bash
# 自动化安装（推荐）
python 安装脚本.py

# 或者手动安装
pip install -r landmark_recognition/requirements.txt
```

## 3. 基本使用测试
```python
# 测试脚本
from landmark_recognition.django_landmark_service import get_landmark_service

# 初始化服务
service = get_landmark_service()

# 健康检查
health = service.health_check()
print(f"服务状态: {health}")

# 识别测试图片
result = service.recognize_from_path('landmark_recognition/tests/images/test1.jpg')
print(f"识别结果: {result}")
```

## 4. Django集成
1. 将 `landmark_recognition/` 目录复制到Django项目中
2. 参考 `landmark_recognition/django_integration_example.py` 文件
3. 修改Django的 `settings.py` 和 `urls.py`
4. 运行Django服务器测试
