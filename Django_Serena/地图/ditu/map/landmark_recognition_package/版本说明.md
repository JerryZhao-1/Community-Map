## 技术栈
- **深度学习**: PyTorch + MobileNetV3
- **图像处理**: PIL/Pillow
- **Web框架**: Django (主要) + Flask (可选)
- **数据格式**: 支持 jpg, png, gif, bmp, tiff
- **Python环境**: conda环境 community_map_env

## 性能指标
- **识别准确率**: >95%
- **平均响应时间**: <500ms
- **支持并发**: 10个请求/秒
- **内存占用**: ~200MB (模型加载后)

## 使用限制
- 仅支持桐梓林地区18个特定地标
- 需要PyTorch环境支持
- 推荐使用GPU加速（可选）
